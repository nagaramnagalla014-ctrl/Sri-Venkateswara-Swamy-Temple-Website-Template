# Sri Venkateswara Swamy vari Devasthanam – Website

Information-only website for **Vanchakalpalathasiddhi Sri Padmavathi, Goda Devi sameta Sri Venkateswara Swamy vari Devasthanam**, Narayanapuram Colony, Poranki, Andhra Pradesh.

Telugu + English · Responsive (mobile, tablet, desktop) · No back end.

## Built with
- HTML5, CSS3, vanilla JavaScript (no frameworks, no build step)
- Google Fonts (Marcellus, Noto Sans Telugu, Lato), Google Maps embed

## Updating content
- Upcoming events and latest updates: `js/data.js`
- Styles: `css/styles.css`
